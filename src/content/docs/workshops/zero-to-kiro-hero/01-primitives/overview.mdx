**By the end of this act you can:** explain what steering files, hooks, and skills
(custom agents) each do — not from a definition, but because you've watched the
agent struggle without one and then comply once it's in place.

## The method: feel the absence, then the fix

Every lesson in this act follows the same loop. We don't tell you what a primitive
is; we show you the agent doing the wrong thing, then add the primitive and watch
the behaviour change.

<CardGrid>
  <Card title="1. Watch it break" icon="warning">
    The instructor drives the agent without the primitive. It uses the wrong
    convention, skips a step, or wanders.
  </Card>
  <Card title="2. Add the fix" icon="approve-check">
    You add the steering file / hook / skill and re-run. The behaviour changes in
    front of you.
  </Card>
</CardGrid>

<Aside type="note" title="Convention used throughout">
Blocks labelled **Instructor demo** are things you watch the facilitator drive.
Blocks labelled **Your turn** are hands-on — that's where you do the work.
A **Checkpoint** at the end of each lesson is where the whole room re-syncs.
</Aside>

This same pattern — *unstructured agent work flails, then structure fixes it* —
scales up to become the spine of Act 2, where the "structure" is a plan.
