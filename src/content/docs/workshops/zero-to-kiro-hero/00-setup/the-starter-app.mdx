Everything from Act 0 on uses one small app, a .NET budget tracker. This step gets it onto
your machine and confirms it runs, so the workshop itself can stay about Kiro, not setup.

## 1. Install the .NET SDK with dotnetup

[`dotnetup`](https://github.com/dotnet/sdk/tree/release/dnup/documentation/general/dotnetup) is
the .NET toolchain manager. It installs and manages .NET at the **user level, no admin required**.

<Steps>

1. Download `dotnetup`:

   <Tabs syncKey="os">
     <TabItem label="macOS / Linux">
       ```bash
       curl -fsSL https://aka.ms/dotnetup/get-dotnetup.sh | bash
       ```
     </TabItem>
     <TabItem label="Windows (PowerShell)">
       ```pwsh
       iwr https://aka.ms/dotnetup/get-dotnetup.ps1 | iex
       ```
     </TabItem>
   </Tabs>

   Follow the printed instructions to add `dotnetup` to your `PATH`, then restart your terminal.

2. Run `dotnetup` and take the suggested first-time setup:

   ```bash
   dotnetup
   ```

   - **Channel:** pick **`10.0`**. The workshop app targets .NET 10.
   - **Mode:** pick **Terminal Mode**.

3. Restart your terminal (or source your profile), then verify:

   ```bash
   dotnet --version
   ```

</Steps>

<Aside type="tip" title="Deterministic alternative: let the repo pick the SDK">
The starter repo pins its SDK in `global.json`. Once you've cloned it (next step) you can skip the
channel choice: run `dotnetup sdk install` inside it and dotnetup installs exactly the .NET the app
needs. `dotnet` then refuses any mismatched SDK, so you can't accidentally end up on the wrong one.
</Aside>

## 2. Clone and run the app

<Steps>

1. Clone the starter repo:

   ```bash
   git clone https://github.com/dwalleck/kiro-hero-budget-tracker.git budget-tracker
   cd budget-tracker
   ```

2. Run it once to confirm everything works:

   ```bash
   dotnet run --urls http://localhost:5000
   ```

3. Open [http://localhost:5000](http://localhost:5000) in your browser. You should see the
   dashboard: this month's spending up top, with the seeded transactions below it.

   <Image src={dashboard} alt="The Budget Tracker dashboard in a browser. A 'Spent this month' figure of $1,300.00 in large red text sits above a Transactions table listing dated rows with description, category, and amount, and an 'Add a transaction' form below." />

</Steps>

<Aside type="note" title="Checkpoint">
Everyone has `dotnet --version` working and the app responding on `http://localhost:5000`.
</Aside>
