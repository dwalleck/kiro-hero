The Kiro IDE is an agentic editor with specs, steering, and hooks built in. If you
prefer to work entirely in the terminal, you can skip this and [install the CLI](../install-kiro/)
instead. Just know that the workshop screenshots and walkthroughs use the IDE.

<Aside type="note" title="System requirements">
- **macOS**: Intel and Apple silicon, with the latest security updates.
- **Windows**: Windows 10 or 11 (64-bit only). ARM is not currently supported.
- **Linux**: glibc 2.39 or higher (e.g. Ubuntu 24+, Debian 13+, Fedora 40+,
  Arch Linux, Linux Mint 22+).
</Aside>

<Steps>

1. Go to [kiro.dev](https://kiro.dev) and download the installer for your
   operating system.

2. Open the downloaded file and follow the installation prompts for your
   platform (Windows, macOS, or Linux).

3. Launch Kiro. On first run you'll be asked to sign in with a provider of your
   choice. You can use a social login or an AWS login.

4. Once signed in, you can optionally import your VS Code settings and
   extensions, pick a theme, and allow Kiro to set up shell integration so the
   agent can run commands on your behalf.

5. You'll land on the welcome page. Open a project to get started.

</Steps>
