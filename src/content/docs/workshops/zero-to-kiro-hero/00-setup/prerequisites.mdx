Before you begin, make sure you have the following ready:

- A supported operating system (macOS, Linux, or Windows 10/11).
- An AWS account with permission to use Kiro.
- Git installed and configured.
- About 90 minutes of uninterrupted time.

<Aside type="tip">
On a managed or corporate machine, confirm you can install IDE extensions and reach
the required AWS endpoints *before* the workshop starts — that's the most common blocker.
</Aside>
