Before you begin, make sure you have the following ready:

- A supported operating system (macOS, Linux, or Windows 11).
- A Kiro account
  - If your account was created through AWS, you will also need your start URL and region your Kiro profile was created in
- An AWS account with the AWS CLI configured.
- Git installed and configured.
