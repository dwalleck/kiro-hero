**By the end of this act you can:** make the agent follow *your* project's conventions and
pull in reusable workflows on demand. You'll have watched it guess wrong without that
context, then get it right once you supply it.

The cold open showed an agent with no idea what your project values. This act fixes that.
Both primitives here answer one question. *What does the agent know?* And both earn their
keep by loading only what's relevant, when it's relevant.

- **Steering files** are durable knowledge about *this* project: conventions, standards, structure.
- **Skills** are reusable *workflows* the agent pulls in on demand, based on what you're asking for.

## The method: feel the absence, then the fix

<CardGrid>
  <Card title="1. Watch it guess" icon="warning">
    Run the agent without the context. It uses the wrong convention or makes an assumption.
  </Card>
  <Card title="2. Add the context" icon="approve-check">
    You add the steering file or skill and re-run. The behaviour changes in front of you.
  </Card>
</CardGrid>

<Aside type="note" title="Convention used throughout">
**Instructor demo** blocks are things you watch the facilitator drive. **Your turn** blocks
are hands-on. That's where you do the work. A **Checkpoint** at the end of each lesson is
where the whole room re-syncs.
</Aside>
